后端工厂与设备选择

backend::createBackend

源码事实：CUDA 构建启用时，auto 调用 createCudaBackend，对任何非 OK 错误都会丢弃错误并选择 CPU；这记录当前实现，不代表期望行为。显式 kCuda 则返回 createCudaBackend 的错误，不进入 CPU fallback。

展开接口、所有权与 Review 要点
所有权
FactoryResult 通过 unique_ptr 独占创建出的 Backend。
输入
Kind：auto、cpu、cuda、openmp 或 rocm
输出
FactoryResult（Backend 或 Error）
执行位置
工厂在 CPU；CPU 后端驻留 Host，CUDA 后端驻留 Device。
失败
显式 kCuda 创建失败时返回其错误；auto 会吞掉 CUDA 工厂的任何错误后尝试 CPU，而 CPU 创建或注册错误仍会返回。

打开源码
