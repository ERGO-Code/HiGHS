Legacy 配对到底是什么意思

同一个实例、同一个后端，candidate 与 frozen legacy 都通过状态、原模型 KKT 和参考目标检查，才是一对可比较数据。

配对几何平均

先对每个有效实例取五次暖态 solver time 的中位数，再求 rewrite / legacy 比值，最后在对数域平均。

r_i = median(candidate_i) / median(legacy_i)
GM = exp(mean(log(r_i)))
